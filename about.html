About AI Campus Emergency Response System

A smart platform designed to improve campus safety and emergency response.

📖 About Project

AI Campus Emergency Response System is a smart web-based application developed to improve campus safety. It enables students, staff, and visitors to report emergencies instantly.

The system provides quick alerts, emergency contacts, and AI-based support to ensure a faster response during critical situations.

This project aims to create a safer and smarter campus environment using modern web technologies.

🎯 Project Objectives

  • Provide quick emergency reporting.
  • Improve campus safety using AI.
  • Send instant emergency alerts.
  • Support faster emergency response.
  • Help students, staff and visitors stay safe.

🚀 Technologies Used

  • HTML
  • CSS
  • Bootstrap 5
  • Python
  • Flask
  • MySQL
